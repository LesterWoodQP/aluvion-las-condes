# res

Resultados agregados: métricas de todas las simulaciones (`corridas.csv`), registro de experimentos y resultados del volumen, las verificaciones y el sub-estudio de exposición. Los resultados binarios de cada simulación (`*.npz`, unos 60 GB) se regeneran con `sim.py`.

`corridas.csv` debe leerse con un lector CSV: una columna tiene una coma en su nombre.
